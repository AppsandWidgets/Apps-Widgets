# UImods GitHub Pages

Publish this folder from the repository's `main` branch `/docs` path.

Site URL:
https://uimods.github.io/AppsWidgets/

The page reads the existing public GitHub release with tag `Apps` and finds the Current Weather and Weather Visual Widget APK assets. Direct download fallbacks remain:

- https://github.com/UImods/AppsWidgets/releases/download/Apps/CurrentWeather.apk
- https://github.com/UImods/AppsWidgets/releases/download/Apps/WeatherVisualsWidget.apk

No website edit is required when those release assets are replaced. The page refreshes release metadata on load and every 5 minutes while open.
